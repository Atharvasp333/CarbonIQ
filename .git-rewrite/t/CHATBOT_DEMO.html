🌱 CarbonIQ Chatbot

Intelligent AI Assistant for Sustainability & Carbon Emissions

📍 To see the chatbot in action:
1. Start the backend: cd backend && python -m uvicorn main:app --reload --port 8000
2. Start the frontend: cd frontend && npm run dev
3. Open http://localhost:5173
4. Look for the floating green button in the bottom-right corner! 🎯
